# 📝 NoteNest

NoteNest is a simple and elegant notes management web application that helps users create, organize, and manage their notes efficiently in one place. It focuses on a clean UI, smooth user experience, and a privacy-first design.

## 🚀 Features

* Create, edit, and delete notes
* Organize notes with title and content
* Instant search and quick access
* Clean and responsive UI
* Data stored locally in the browser (no backend)

## 🛠️ Tech Stack

* React (Vite)
* Tailwind CSS
* JavaScript
* Browser localStorage

## 📂 Project Setup

```bash id="1a2b3c"
npm install
npm run dev
```

Open the displayed localhost URL in your browser.

## 🎯 Purpose

This project was built as a learning-focused frontend application to practice CRUD operations, component-based architecture, and modern UI development.

## 🔒 Privacy

All notes are stored locally in the user’s browser. No data is sent to any server.
